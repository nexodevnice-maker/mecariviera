# CONTENT TRUTH

## Statuts
- `CONFIRMED` : fourni / vérifié par une source fiable du projet.
- `TO_CONFIRM` : plausible mais doit être confirmé avant publication.
- `UNKNOWN` : absent.
- `REQUIRED_BEFORE_PUBLICATION` : indispensable avant mise en ligne commerciale.

## Identité
- MECA RIVIERA : `CONFIRMED`
- activité de mécanique automobile à domicile : `CONFIRMED`
- présence sur Snapchat : `CONFIRMED`
- entreprise déjà déclarée : `UNKNOWN / ne pas affirmer`
- forme juridique : `UNKNOWN`
- SIREN/SIRET : `UNKNOWN`
- adresse professionnelle : `UNKNOWN`
- assurances / certifications / qualifications : `UNKNOWN`

## Services issus du support fourni
Entretien/vidange/filtres ; freins ; diagnostic ; batterie ; climatisation ; suspension/amortisseurs/train avant ; échappement ; révision constructeur.

Les services doivent être validés pour la publication finale si leur formulation implique une promesse précise.

## Contacts
Les numéros présents sur le support peuvent être intégrés au prototype, mais doivent être revalidés avant publication.

## Règle
Ne jamais transformer `TO_CONFIRM` ou `UNKNOWN` en fait.
