# MECA RIVIERA — PROJECT INSTRUCTIONS V2.1

## Positionnement
MECA RIVIERA est une activité de mécanique automobile à domicile actuellement présente sur Snapchat et destinée à évoluer vers une entreprise structurée.

Le site doit être conçu et exécuté comme un **projet professionnel prêt à devenir le site d'une entreprise automobile**, sans surjouer les questions juridiques ou administratives pendant la production.

Le statut actuel ne doit jamais être inventé. On ne publie pas de numéro, certification, adresse professionnelle, forme sociale ou autre donnée non confirmée.

## Objectif
Créer un site premium, moderne, automobile et local, qui transforme une présence sociale en présence web professionnelle et crédible.

Le site doit vendre une idée simple :
**la mécanique vient au véhicule.**

## Règles non négociables
- priorité au rendu réel et à l'expérience utilisateur ;
- aucune esthétique template / SaaS / dashboard / carte immobilière ;
- pas d'effets gratuits ;
- mobile traité comme une vraie expérience ;
- aucune information commerciale inventée ;
- les informations inconnues restent `TO_CONFIRM` jusqu'à validation ;
- vérifier le rendu réel après chaque milestone ;
- corriger avant de poursuivre ;
- Claude peut contredire une décision si elle dégrade clairement le résultat.

## Niveau attendu
Professionnel, premium, crédible, rapide, local, automobile.

Ne pas reproduire BELVÉDÈRE ni son niveau de gouvernance. Réutiliser seulement les enseignements utiles sur l'immersion, le mouvement, la QA et la qualité visuelle.

## Processus
BUILD → RUN → INSPECT → CRITIQUE → CORRECT → RECHECK

Un build réussi ne constitue jamais une validation visuelle.
