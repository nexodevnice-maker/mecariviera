# PUBLICATION READINESS

Checklist finale courte :
- identité publique correcte ;
- informations commerciales confirmées ;
- coordonnées confirmées ;
- contenu et claims validés ;
- destination des formulaires opérationnelle ;
- domaine/hébergement maîtrisés ;
- confidentialité / cookies / mentions nécessaires préparés ;
- médias et assets utilisables ;
- tests desktop/mobile ;
- performance acceptable ;
- accessibilité acceptable ;
- SEO technique vérifié.

Ce gate est un contrôle de mise en ligne, pas un frein à la production créative.
