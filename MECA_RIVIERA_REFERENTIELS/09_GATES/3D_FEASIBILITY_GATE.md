# 3D FEASIBILITY GATE

Avant d'engager une scène complexe :
- inspecter le GLB ;
- compter géométries / triangles ;
- vérifier textures ;
- vérifier possibilité réelle d'interaction ;
- mesurer coût ;
- définir fallback.

Ne jamais promettre des hotspots ou une décomposition mécanique que le modèle ne permet pas réellement.
