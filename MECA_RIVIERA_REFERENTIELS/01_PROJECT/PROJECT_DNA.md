# MECA RIVIERA — PROJECT DNA

## Essence
Une activité de mécanique automobile de proximité qui apporte le service directement au véhicule du client.

## Promesse centrale
**La mécanique vient au véhicule.**

## Territoire
Alpes-Maritimes / Côte d'Azur, avec priorité à la compréhension locale et à la conversion.

## Ton
- professionnel
- rassurant
- direct
- technique sans être froid
- premium sans être prétentieux
- local sans cliché touristique

## Expérience
Le site doit donner immédiatement :
1. confiance ;
2. compréhension ;
3. désir de contacter ;
4. perception d'un service réellement mobile.

## Anti-patterns
- hero générique de garage ;
- grille de services sans narration ;
- grosses cartes arrondies ;
- gradients gratuits ;
- 3D décorative ;
- animations constantes ;
- jargon technique inutile ;
- faux avis ;
- fausses certifications ;
- faux chiffres ;
- imitation de concessionnaire officiel.

## Référence visuelle
Les assets automobiles doivent servir la démonstration du savoir-faire et de la mobilité, pas devenir un showroom virtuel gratuit.
